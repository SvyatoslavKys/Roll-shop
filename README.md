# Roll Shop

A small educational roll delivery website built with HTML, CSS and JavaScript.

## Pages

- `index.html` — the home page with an introduction and popular products.
- `catalog.html` — the product catalogue, cart and demo checkout form.

## Features

- product quantity controls;
- identical products combined into one cart item;
- automatic order total calculation in Polish złoty;
- cart persistence with `localStorage`;
- responsive layout based on Bootstrap 4;
- demo checkout without sending personal data.

Open `index.html` in a browser or serve the project with any local static server.
